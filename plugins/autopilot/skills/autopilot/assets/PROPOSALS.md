# PROPOSALS (autopilot 기능 제안)

루프가 스스로 하지 않는 큰 변경을 사람에게 넘기는 곳. 상태 칸만 바꾸면 된다.
- `채택`: 다음 발굴에서 기능 문서와 작업으로 만든다 (공개 인터페이스 변경도 여기 적힌 범위까지 허용)
- `거절`: 다시 제안하지 않는다
- `보류`: 나중에 다시 본다
- `제안`(새 항목) → 사람이 위 셋 중 하나로 바꾼다. 채택된 항목은 루프가 `진행` → `완료`로 바꾼다
