# Security Policy

Please do not report security vulnerabilities through public issues, pull requests, or discussions. Instead, report them privately using GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** (a private security advisory) at https://github.com/yuapi/Autopilot/security/advisories/new. Include the affected version (the `metadata.version` in `SKILL.md`), a description of the issue, steps to reproduce, and its potential impact; reports will be acknowledged and handled privately until a fix is released.
